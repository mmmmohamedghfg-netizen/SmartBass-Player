# SmartBass Player 🎵

تطبيق تشغيل أغاني أندرويد احترافي مع **ذكاء اصطناعي محلي** + **استوديو صوت قوي**.

## المميزات الكاملة

### 🎧 التشغيل
- تشغيل كل الأغاني من الجهاز
- شريط تقدم + Seek
- تكرار (واحدة / الكل / إيقاف)
- عشوائي (Shuffle)
- مؤقت نوم مع **Fade Out** تدريجي
- سرعة التشغيل من 0.5x إلى 2x
- التحكم في مستوى الصوت داخل التطبيق

### 🧠 الذكاء الاصطناعي (أوفلاين 100%)
- المكس الذكي بناءً على الاستماع + المفضلة
- تخمين نوع الأغنية
- **باس ذكي تلقائي** حسب النوع

### 🔊 استوديو الصوت
- Bass Boost قوي جدًا
- Loudness Enhancer
- Surround / Virtualizer
- **Power Mode** (أقوى وضع)
- إعدادات مسبقة متعددة

### ❤️ المفضلة والقوائم
- مفضلة
- قوائم تشغيل
- الأكثر تشغيلًا + آخر ما استمعت
- بحث سريع

### 🌑 المظهر
- وضع AMOLED أسود نقي
- اختيار لون التطبيق (5 ألوان)

## رفع على GitHub → APK جاهز

1. ارفع محتويات مجلد `SmartMusicPlayer`
2. ادخل على **Actions**
3. استنى **Build APK** يخلص
4. حمّل الـ APK من Artifacts
